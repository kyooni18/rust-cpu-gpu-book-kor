이 책에서 다룬 각 분야를 더 깊게 공부할 때 참고하기 좋은 자료를 정리했습니다.

## 컴퓨터 아키텍처 전반

- **Computer Systems: A Programmer's Perspective (CS:APP)** (Bryant & O'Hallaron) —
  프로그래머 관점에서 하드웨어와 시스템을 배우는 대표적인 교재입니다.
  Part I의 내용을 더 체계적으로 공부하고 싶을 때 좋은 출발점입니다
- [**What Every Programmer Should Know About Memory**](https://people.freebsd.org/~lstewart/articles/cpumemory.pdf)
  (Ulrich Drepper) — 메모리 계층과 캐시에 관한 고전적인 글입니다.
  2007년에 작성됐지만 2장의 주제를 더 깊게 이해하는 데 여전히 가치가 있습니다
- [**Agner Fog's optimization manuals**](https://www.agner.org/optimize/) —
  x86 명령어 지연 시간과 저수준 최적화 기법을 폭넓게 다룹니다.
  어셈블리 수준까지 파고들고 싶을 때 매우 유용합니다

## Rust 성능

- [**The Rust Performance Book**](https://nnethercote.github.io/perf-book/) —
  Rust 성능 개선 기법을 간결하게 정리한 무료 전자책입니다.
  이 책의 Part II를 실무적으로 보완하기 좋습니다
- [**Rust Atomics and Locks**](https://marabos.nl/atomics/) (Mara Bos) —
  원자적 연산과 메모리 오더링을 깊게 다루는 무료 공개 책입니다.
  5장과 17장의 내용을 더 자세히 공부하기 좋습니다
- [**The Rustonomicon**](https://doc.rust-lang.org/nomicon/) —
  unsafe Rust를 다루는 공식 가이드입니다. `get_unchecked` 같은 저수준 API를 사용하기 전에 읽을 가치가 있습니다

## GPU

- [**WebGPU 사양**](https://www.w3.org/TR/webgpu/) /
  [**WGSL 사양**](https://www.w3.org/TR/WGSL/) — 가장 직접적인 1차 자료입니다
- [**Learn wgpu**](https://sotrh.github.io/learn-wgpu/) —
  wgpu의 대표적인 튜토리얼입니다. 그래픽스 중심이지만 11장 이후로 넘어가기 좋습니다
- [**wgpu 공식 예제**](https://github.com/gfx-rs/wgpu/tree/trunk/examples) —
  이 책의 GPU 코드도 공식 예제에서 많은 구조를 참고했습니다
- **CUDA C++ Programming Guide** (NVIDIA) — CUDA를 공부할 때 가장 중요한 1차 자료입니다.
  워프, 공유 메모리, 코얼레싱처럼 9~10장에서 다룬 개념을 NVIDIA 관점에서 자세히 설명합니다
- [**burn**](https://burn.dev/) / [**candle**](https://github.com/huggingface/candle) —
  Rust 머신러닝 프레임워크입니다. 단순히 행렬 연산을 빠르게 수행하는 것이 목적이라면 직접 커널을 작성하기 전에 검토할 만합니다

## 응용편 다음 단계

- **Computer Architecture: A Quantitative Approach** (Hennessy & Patterson) —
  컴퓨터 아키텍처를 정량적으로 연구하는 대표적인 교재입니다. Part IV 이후 내용을 더 깊게 다룹니다
- [**Operating Systems: Three Easy Pieces**](https://pages.cs.wisc.edu/~remzi/OSTEP/) (OSTEP) —
  가상 메모리(14장)와 OS 계층(27장)을 체계적으로 공부할 수 있는 무료 공개 교재입니다
- **Systems Performance** (Brendan Gregg) —
  27~28장의 실무 주제인 성능 측정, OS, 클라우드 성능 분석을 깊게 다룹니다
- **Programming Massively Parallel Processors** (Hwu, Kirk & Hajj) —
  Part VI의 GPU 커널 최적화를 CUDA로 더 깊게 공부할 때 널리 사용되는 교재입니다
- [**Async Book**](https://rust-lang.github.io/async-book/) /
  [tokio 튜토리얼](https://tokio.rs/tokio/tutorial) — 19장 이후의 async 실무를 이어서 공부하기 좋습니다
- [crossbeam](https://github.com/crossbeam-rs/crossbeam) — 17장에서 다룬 동시성 자료구조와 메모리 회수 도구를 제공합니다
- [HdrHistogram](https://github.com/HdrHistogram/HdrHistogram_rust) — 28장의 지연 시간 분포 측정에 널리 사용됩니다
- [iai-callgrind](https://github.com/iai-callgrind/iai-callgrind) — 명령어 수 기반의 안정적인 벤치마크 도구입니다(28장)

## 이 책의 코드

이 책에서 실행할 수 있는 코드는 저장소의 `src/snippets/`와 `examples/`에 있습니다.
`src/snippets/`는 브라우저 실행을 위한 코드이고, `examples/`는 로컬 실행과 GPU 예제를 포함합니다.

책에 나온 수치는 저자의 Apple M4 및 Rust Playground 환경에서 측정한 값입니다.
하드웨어와 실행 환경이 달라지면 결과도 달라집니다.
직접 자신의 환경에서 다시 측정해 보세요.
그 과정 자체가 8장에서 배운 성능 측정 원칙의 실천입니다.
